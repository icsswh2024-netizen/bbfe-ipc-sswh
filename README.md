# BBFE IPC SSWH — Occupational Exposure Registry

เว็บแอปบันทึกและติดตามอุบัติเหตุจากการให้บริการทางการแพทย์และสาธารณสุข สำหรับงานป้องกันและควบคุมการติดเชื้อ โรงพยาบาลศรีสังวรสุโขทัย

พัฒนาจาก **แบบบันทึกและรายงานอุบัติเหตุในการให้บริการทางการแพทย์และสาธารณสุข Form IC 1, Version 2.0 วันที่ 4 สิงหาคม 2568** ครบทั้ง 2 หน้า

## ความสามารถ

- บันทึกข้อมูลบุคลากร เหตุการณ์ และชนิดการสัมผัส
- บันทึกผลเลือดผู้ป่วยต้นเหตุและบุคลากร Day 0
- บันทึกความยินยอม สูตรยา PEP, CBC, Creatinine และ LFT
- ติดตามผลเดือนที่ 1, 3 และ 6
- ค้นหา แก้ไข ลบ และพิมพ์รายงาน
- Dashboard แสดงจำนวนทั้งหมด รายการรอติดตาม และรายการเดือนปัจจุบัน
- ส่งออก CSV และสำรองข้อมูล JSON
- Responsive ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ

## การใช้งาน

เปิด `index.html` ในเว็บเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages ได้ทันที ไม่มีขั้นตอน build

> ข้อมูลถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น ควรสำรอง JSON เป็นประจำ และไม่ควรใช้เป็นฐานข้อมูลส่วนกลางโดยไม่มีระบบยืนยันตัวตน การเข้ารหัส และการสำรองข้อมูลที่เหมาะสมกับข้อมูลสุขภาพ
