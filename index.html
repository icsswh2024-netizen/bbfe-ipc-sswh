↗ เปิดชีต fields

เชื่อมต่อเพื่อ “บันทึกลงชีต” อัตโนมัติ

ทำครั้งเดียวเท่านั้น หลังจากนี้กดปุ่มบันทึกได้ทันที ระบบจะเขียนคอลัมน์ สถานะ ลงแท็บ fields ให้เอง

  1. เปิดชีต → เมนู ส่วนขยาย (Extensions) → Apps Script
  2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างนี้ (กดปุ่มคัดลอกโค้ด) → บันทึก
  3. กด Deploy → New deployment → เลือกชนิด Web app
  4. ตั้ง Execute as: Me และ Who has access: Anyone → Deploy แล้วคัดลอก Web app URL
  5. วาง URL ในช่องด้านล่าง → กด “บันทึกการเชื่อมต่อ”
