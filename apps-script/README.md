# Apps Script (ตัวเขียนข้อมูลลงชีต)

`Code.gs` คือโค้ด Google Apps Script Web App ที่แอปใช้เขียนข้อมูลลงชีต
`IC-รายงาน-อุบัติเหตุเจ้าหน้าที่` แท็บ `01-บันชีรายชื่อ`

ต้นฉบับฝังอยู่ใน `app.js` (ตัวแปร `APPS_SCRIPT_CODE`) — ไฟล์นี้คือเวอร์ชันที่
แทนค่า `SHEET_ID` และชื่อคอลัมน์เรียบร้อยแล้ว พร้อมวางใน Apps Script ได้เลย

## วิธี Deploy
1. เปิดโปรเจกต์ Apps Script **IC-รายงาน-อุบัติเหตุเจ้าหน้าที่**
2. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจาก `Code.gs` ทับ
3. Deploy → Manage deployments → ✏️ แก้ไข → Version: **New version** → Deploy
4. กลับมาที่แอป กด "ทดสอบการเชื่อมต่อ" ควรขึ้นเวอร์ชันตรงกับ `IC_VERSION`

## เวอร์ชันปัจจุบัน: 2568-09-28.9
- สร้างคอลัมน์ `JSON` / `ลายเซ็น` / `ลายเซ็นVCT` อัตโนมัติถ้ายังไม่มี
- เก็บลายเซ็นแยกเซลล์ ไม่ถูกตัดแม้ข้อมูลใหญ่
- ข้ามช่อง dropdown/validation ที่ค่าไม่ตรงโดยอัตโนมัติ (เช่น หน่วยงาน)
